# Shoebill downloads

Download files for **Shoebill Text Editor**, a fast, lightweight text and code editor.

This repository holds the finished release files only. It has no source code.

## Get Shoebill

- **Website and instructions:** https://shoebill-editor.app/
- **Download page:** https://shoebill-editor.app/download
- **Release files:** see [Releases](../../releases). Each release has the AppImage for Linux and a `SHA256SUMS` file.

## Check a download

Put the file and `SHA256SUMS` in the same folder and run:

```bash
sha256sum -c SHA256SUMS --ignore-missing
```

You should see `OK` next to the file you downloaded.
